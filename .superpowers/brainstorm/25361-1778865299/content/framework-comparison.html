前端框架选择 — 哪个适合你的 Deep Research Agent？

基于你的项目特点：SSE 实时流、多阶段进度可视化、Markdown 报告渲染、未来可能扩展对话界面

A

React + Vite + shadcn/ui

最主流的前端框架，生态最丰富。shadcn/ui 提供高质量的 Headless UI 组件，Tailwind CSS 做样式。对 SSE/EventSource 支持成熟，状态管理用 Zustand 或 Jotai 非常简洁。

Pros

  • 生态最强，几乎所有 AI SDK 都有 React 优先支持
  • shadcn/ui 组件美观、可定制、代码直接在你项目里
  • Vercel AI SDK 可直接对接 SSE 流，内置 useChat hook
  • 招聘/协作最容易找到开发者

Cons

  • 学习曲线较陡（JSX、Hooks、状态管理）
  • 文件/目录结构需要自己设计
  • 容易引入过多依赖导致项目臃肿
B

Vue 3 + Vite + Nuxt UI / Element Plus

上手最简单，中文文档完善，模板语法直观。Nuxt UI 或 Element Plus 提供完整的企业级组件库，SSE 通过原生 EventSource 即可处理。

Pros

  • SFC 单文件组件，HTML/CSS/JS 天然分离，学习成本最低
  • 中文文档/社区极好，适合国内开发者
  • Composition API 提供清晰的逻辑组织方式
  • Pinia 状态管理比 Redux 简单得多

Cons

  • AI SDK 生态不如 React 丰富（如 Vercel AI SDK 只支持 React）
  • 组件库风格偏企业后台，个性化需要更多定制
  • 国际化项目中招聘略逊于 React
C

Python 前端：Gradio / NiceGUI

完全不需要写 JavaScript，纯 Python 即可构建 UI。Gradio 专为 AI/ML 场景设计，内建流式输出支持。NiceGUI 更灵活但社区较小。

Pros

  • 零前端知识要求，全 Python 栈
  • Gradio 内建 ChatInterface、流式输出，5 行代码搞定
  • 和 FastAPI 天然结合（NiceGUI 基于 FastAPI）
  • 部署简单，一个 Python 进程

Cons

  • UI 定制化非常受限，很难做成"精致的专业产品"
  • 复杂交互（如自定义 stepper、动画）几乎无法实现
  • 性能不如 JS 框架，页面响应慢
  • 你刚刚决定离开 Streamlit，Gradio 的问题类似
