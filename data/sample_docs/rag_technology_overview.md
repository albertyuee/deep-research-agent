# RAG（检索增强生成）技术概述

## 什么是 RAG

RAG（Retrieval-Augmented Generation）是一种将信息检索与大语言模型相结合的架构范式。在生成回答之前，RAG 系统先从外部知识库中检索相关信息，然后将检索结果作为上下文提供给 LLM，从而显著减少幻觉、保持知识的时效性。

## RAG 的演进阶段

### 1. 朴素 RAG（2023）
基本的"索引-检索-生成"流水线：文档分块 → Embedding → 向量存储 → 相似度检索 Top-K → 拼接上下文 → LLM 生成。简单直接，但在复杂查询上表现有限。

### 2. 高级 RAG（2024）
引入多种优化策略：
- **查询路由**：根据查询类型选择不同的检索策略
- **混合检索**：稠密向量 + 稀疏 BM25 + RRF 融合
- **重排序**：Cross-Encoder 对粗排结果精排
- **查询改写**：HyDE、Multi-Query 等技术增强检索召回

### 3. Agentic RAG（2025-2026）
将 Agent 范式引入 RAG 链路：
- Agent 自主规划检索步骤
- 自我评估检索质量
- 条件性重试与策略调整
- 多源信息聚合与冲突消解

## GraphRAG 与知识图谱增强

Microsoft GraphRAG 通过构建实体知识图谱 + 社区检测，实现了对全局性、多跳推理问题的回答能力。LightRAG 以更低的计算成本实现了类似的图增强效果，并支持增量更新。

## 关键指标

| 指标 | 朴素 RAG | Agentic RAG |
|------|---------|------------|
| 单跳事实查询 | 85% | 92% |
| 多跳推理 | 35% | 78% |
| 全局总结 | 不可用 | 可用 |
| 幻觉率 | ~15% | ~5% |
| 平均延迟 | 1-2s | 3-8s |

## 未来方向

- 多模态 RAG（图文音视频统一检索）
- 实时知识更新（流式索引）
- 个性化 RAG（用户画像驱动检索偏好）
- 边缘设备 RAG（本地轻量部署）
